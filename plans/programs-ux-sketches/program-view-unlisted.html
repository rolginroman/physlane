program-view-unlisted

P0 Same renderer + share-link banner · /u/$authorSlug/$programSlug/$shareToken (noindex) · journeys A1–A4, A6, C3, C5

Differences from program-view only: (1) a one-line banner for viewers, (2) the author line is plain text — no profile link, no "Author" card (an unlisted-only author has no profile page), (3) the owner gets link controls instead of the public owner bar. Viewer copy never says draft, unlisted, token, rotate, or revision.

1 · Anonymous viewer

Banner wording uses the canonical "share link" term (CONTEXT.md) rather than "private link" — see design-notes §5 Q2. Everything below the banner is the public renderer.

2 · Owner opens own share link (C3, C5)

Owner-only bar: state in plain words, then Copy link / Replace link / Edit. The viewer banner and Report link are not shown to the owner. "Replace link…" is the author-facing label for rotation; the confirm states the consequence before anything changes.

3 · State matrix — same layout, swapped region

Signed-in viewer: banner + one-tap copy (program-view §4). Loading / error / empty week / minimal / long content: identical to program-view §6–§7 with the banner on top. Report sheet: identical. Dead or replaced link: plain 404 → program-not-found (no hint that a link existed). Deleted: program-removed. Program now public: token URL 301s to the public URL, so the viewer lands on program-view without the banner.
