P0 Dialog from the editor · journeys B2 · catalog + custom exercises

Search first (autofocus, matches names and aliases). Filters narrow, never gate: region → muscle (two-tier taxonomy, 8 → 25), then equipment. Tabs: Catalog / My exercises. A miss offers "Create custom exercise" with the typed name — same schema as catalog, primary muscle required. Mobile: full-screen dialog. Desktop: centered dialog, filters in a left column.

1 · Browse with filters · search

Selecting a region reveals its muscles as a second chip row. Result rows: name, primary muscle · equipment, and an asset hint (Video / Article) so authors know what viewers will get. Tap a row → entry added with default 3 × 10, picker closes, the new row opens expanded in the editor.

2 · No match → create custom exercise inline

Same fields as a catalog exercise. Required: name, primary muscle (grouped by region), equipment. Optional: secondary muscles, form note. Created exercises belong to the author and appear under My exercises.

3 · Loading · error · long list

Anonymous / owner split does not apply (author-only tool). Minimal = no filters selected, empty search: the full catalog A–Z. Long list: virtualised scroll; the count line stays visible.
