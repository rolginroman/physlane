program-removed

P1 Deleted program at a known address · distinct from 404 · noindex · no content

Shown when the address resolves to a program its author deleted (soft delete). No title, no content, no copy button. Distinct from 404 so a visitor knows the link was right and the program is gone — not mistyped. Owners who delete see this too if they revisit; nothing is restorable from the UI.
