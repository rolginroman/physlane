P0 Shared renderer, public variant · /u/$authorSlug/$programSlug · journeys A1–A6, C5

One markup per frame; container queries switch the 390px column to the 1280px two-column layout. Content first, no interstitial, no login wall. Week tabs and session accordions are clickable.

1 · Populated + long content — anonymous viewer (A1–A3)

Hero answers whose / goal / level / sessions per week / length above the fold (A2). 12 week tabs scroll horizontally; first session open, the rest collapsed with exercise and set counts so the week reads as a list, not a grid (A3 dip). 8-entry session with a 2-exercise and a 3-exercise superset. Sets-by-region summary sits at the top of each open session.

2 · Exercise asset drawer (A4)

Tap an exercise name. Mobile: bottom sheet. Desktop: right side panel (same markup). Catalog facts, first video inline (click to load — nothing from youtube.com loads until the play tap), catalog form note, the author's prescription and cues for this entry, then "References". Focus moves to Close on open (ring drawn).

3 · Copy as anonymous → sign-in door (A6) → return

"Copy to my programs" never navigates away cold. A sheet states what happens and offers both account paths; the program stays underneath. After auth the viewer returns to the same URL with the copy prompt pinned — one tap completes it.

4 · Signed-in viewer (lb preference) — copy states

Signed-in viewers copy in one tap. Loads render in the viewer's unit (lb here); never both units. %1RM is unit-free.

5 · Owner viewing own public program (C5)

Subtle owner bar replaces nothing in the content; it adds Edit and Share. Hidden for the owner: copy CTA and "Report this program". Owner sees exactly what visitors see below the bar.

6 · Minimal content — Leo's bare program

Empty description → no paragraph, no placeholder. One week → no week tabs. No rest / intensity / cues / assets → those slots simply do not render; entries stay one line of prescription. Hero still answers A2 from tags alone.

7 · Empty week · loading · error · report

"Empty" for a viewer = a week with no sessions (weeks count exceeds authored weeks). Skeleton covers client-side navigation only — first load is server-rendered. Error = client navigation fetch failed. Report is anonymous-capable, free text, footer-only.
